# 归档 · 快捷指令 + 背面轻点（旧采集方案）

> 新形态改用自研 App 自带录音，本页只留踩过的结论，供 iOS 阶段参考。
> 归档时间：2026-11-08。

## 当时怎么做的

三条快捷指令：`idea 开始`（创建录音）绑轻点背面两下、`idea 结束`（停止录音 → 查找最新一条 → 打开）绑三下、`idea 分析`（从共享表单收音频，POST 到服务端）手动触发。

## 验证过的结论

1. **息屏、手机放口袋里，轻点背面照样能触发快捷指令** —— 免解锁启动录音这条是成立的。
2. **快捷指令拿不到语音备忘录的音频字节**。「查找录音」返回的是文本（约 45 字节的标题），拿去上传服务端收到的是 `.txt`，ffmpeg 报 `Invalid data found when processing input`；「存储到文件」落盘的也是 txt。iOS 26.7.1 上确认。唯一能拿到真音频的通道是共享表单，所以最后一步必然手动。
3. 因此「停录 → 自动上传」在快捷指令里走不通，**自研 App 才能闭环**（音频在自己沙盒里）。
4. 上传失败手机不报错（「获取 URL 内容」的结果默认丢弃），调试期要加「显示结果」动作。

## 对 iOS 阶段的意义

- 自研 App 需要两个 App Intent：开始录音、停止并处理，仍然绑轻点背面两下 / 三下。
- 真正要实测的是「App 没启动时 App Intent 冷拉起录音」这条系统路径。
